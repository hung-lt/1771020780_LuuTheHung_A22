# Portfolio cá nhân – Lưu Thế Hưng

Website portfolio giới thiệu bản thân, kỹ năng, dự án học tập và thông tin liên hệ. Trang được xây dựng bằng HTML và CSS, có bố cục responsive cho máy tính và thiết bị di động.

## Nội dung website

- **Giới thiệu:** thông tin và định hướng cá nhân.
- **Kỹ năng:** HTML, CSS, JavaScript, Java, C++, SQL, Git/GitHub và kỹ năng mềm.
- **Dự án:** giao diện ứng dụng quản lý sinh viên, website đặt phòng khách sạn và ứng dụng nghe nhạc.
- **Học tập:** thông tin học tập và sản phẩm thực hành.
- **Liên hệ:** email, GitHub và biểu mẫu gửi lời nhắn.

Biểu mẫu liên hệ hiện dùng phương thức GET để thực hành HTML. Biểu mẫu chưa gửi email và không lưu dữ liệu lên máy chủ.

## Chạy website

Không cần cài đặt thư viện. Mở `index.html` bằng trình duyệt, hoặc chạy một máy chủ tĩnh tại thư mục `portfolio` rồi truy cập trang qua địa chỉ máy chủ.

## Công nghệ sử dụng

- HTML5
- CSS3 (Flexbox, Grid và media queries)
- Google Fonts – Inter

## Tùy chỉnh

- Cập nhật nội dung, liên kết và thông tin liên hệ trong `index.html`.
- Cập nhật màu chủ đạo trong hai biến `--accent` và `--accent-dark` ở đầu `css/style.css`.
- Thay ảnh trong thư mục `assets` và cập nhật đường dẫn tương ứng trong `index.html`.
